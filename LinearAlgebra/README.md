## 기록 방법

- 개념 하나당 `concepts/` 에 파일 하나. `concepts/_템플릿.md` 를 복사해서 시작.
- **핵심은 "막힌 부분" 칸이다.** 코테 오답 정리와 같은 원리 —
  이해한 것보다 못 이해한 것을 적어야 나중에 쓸모가 있다.
- 매 세션 첫 10분은 지난 노트를 다시 읽는 데 쓴다.

## 세션 진행 방식

**학습 세션 (개념을 처음 만나는 날)**
1. 지난 노트 훑기 (10분)
2. 3Blue1Brown 해당 편 시청
3. `_템플릿.md` 복사해서 "한 문장으로", "기하학적으로 무슨 뜻인가" 칸 채우기
4. 이해 안 된 것을 "막힌 부분"에 적어두고 그날은 끝낸다 — 그날 다 이해하려 하지 않는다

**연습 세션 (손으로 푸는 날)**
1. 지난 노트의 "막힌 부분" 다시 읽기 (10분)
2. Khan Academy 해당 단원 문제 풀기
3. 가장 작은 크기(2x2, 2차원)로 손계산 하나를 노트의 "손으로 풀어본 예제"에 남기기
4. 풀린 것이 있으면 "막힌 부분"에 어떻게 풀렸는지 추가한다
